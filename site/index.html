What it does

A chord sheet, not a guess.

Every view comes from the same analysis: key, beat grid, bars, chords and the parts where someone is singing.

  1. 01

    Detect

    Essentia reads the audio, estimates the key and finds chord changes. Viterbi smoothing stops the sheet flickering between similar chords.

    NNLSChroma
  2. 02

    Align

    Lyrics line up with the parts where someone is singing. When a line drifts, move an anchor and the rest follows.

    Vocal regions
  3. 03

    Practice

    Arm A and B in the grid, preview a bar on hover, then play the range or loop it. Slow the tempo down and count in before you start.

    A–B loop
  4. 04

    Shape

    Transpose, add a capo, simplify or reduce chords. Switch between guitar, piano and ukelele diagrams, with sharps, flats or solfège.

    Guitar · piano · uke
  5. 05

    Keep

    Save songs and setlists in a local library with practice history. Export ChordPro, print a PDF, back everything up as JSON or send the sheet to WhatsApp, Telegram or email.

    Local library

From audio to practice

Three steps, no account.

Bring a link or a file. The analyzer does the timing, you keep the musical decisions.

  1. 01

    Add a source

    Paste a YouTube link or choose an audio file. Uploads support MP3, WAV, M4A, OGG, FLAC, WebM and MP4.

  2. 02

    Let the analyzer work

    Beats, bars, key and chords are detected locally. The first run loads the models and takes a little longer.

  3. 03

    Fix, save, practice

    Correct any chord in the editor, add lyrics, then save to your library or setlists. Nothing leaves your machine.

Run it your way

A desktop app, or your own server.

The desktop build bundles the analyzer. The Docker stack puts the same app on a laptop, a home server or a VPS.

01

Windows preview

Unsigned

An NSIS installer built by CI. It bundles the analyzer, ffmpeg and the ONNX models. It is unsigned, so SmartScreen will warn: choose More info, then Run anyway.

A SHA-256 checksum is published with every release.

Download the installer Install guide
02

macOS preview

Not notarized

DMG and ZIP builds for Apple Silicon and Intel. They are ad-hoc signed, not notarized, so Gatekeeper will ask you to allow the app in Privacy and Security.

macOS 13 or later on Intel, macOS 15 or later on Apple Silicon. A SHA-256 checksum is published with every release.

Download the DMG macOS guide
03

Linux preview

x64

AppImage and .deb for x86_64. The analyzer, ffmpeg and the ONNX models are bundled. The AppImage is portable; the .deb installs with apt.

Built on Ubuntu 22.04 for glibc 2.35 or later. The AppImage may need FUSE. A SHA-256 checksum is published with every release.

Download the AppImage Linux guide
04

Docker

Clone the repository and start the stack. The first build installs Essentia, ONNX Runtime, ffmpeg and the models. 

git clone https://github.com/moiseslodeiro/chordifree.git
cd chordifree
docker compose up --build -d

Then open http://localhost:3000.

Docker guide
05

Self hosted web app

Put the web app behind HTTPS to install it as a PWA. The API and the analyzer still run on the same host.

Deployment notes

Local by design

Your songs stay with you.

Chordifree has no accounts and no tracking. The library lives in your browser, and the desktop build keeps the analyzer on your computer.

No accounts
Open the app and start. Nothing to sign up for.
Local library
Songs, setlists and practice history stay in local storage. Export them whenever you want.
Your audio
Uploads are analyzed and not kept in the library. Temporary files are removed.

YouTube downloads may violate YouTube's Terms of Service. Use audio upload when you do not own the content.

Questions

Before you start.

The short answers. The README has the details, the environment variables and the architecture.

Do I need an account?

No. There is no sign up, no login and no tracking.

Does it upload my audio to a third party?

No. The web app sends audio only to the API and analyzer you run. The desktop build keeps everything on your computer.

Do the desktop builds need Docker?

No. The Windows, macOS and Linux installers bundle the analyzer, ffmpeg and the ONNX models. Docker is the alternative for the web app and servers.

Is the Windows build signed?

Not yet. It is a preview built by CI, so SmartScreen will warn: choose More info, then Run anyway. Verify the SHA-256 from SHA256SUMS.txt before running.

Why does macOS block the app?

The macOS build is ad-hoc signed and not notarized. Allow it in System Settings → Privacy & Security, then open it again. The macOS install guide has the steps.

Is there an ARM Linux build?

Not yet. Essentia does not publish an arm64 Linux wheel, so the Linux desktop build is x86_64 only. An ARM build would need Essentia compiled from source.

Does YouTube work?

Yes, through yt-dlp. Downloading YouTube audio may violate its Terms of Service, so prefer your own files when you do not own the content.

Where are my songs stored?

In your browser's local storage for the web app, and on your computer for the desktop app. Export JSON for backups or ChordPro for other tools.

Can I use it offline?

The installed desktop app works without an internet connection. The web app needs the API and analyzer running, but the app shell can be installed as a PWA.

Which instruments and languages?

Guitar, piano and ukelele; English and Spanish; sharps, flats, solfège, capo, transposition, simplified and reduced chords.

Is it free?

Yes. Chordifree is open source under AGPL-3.0.
